Device Registry API

A serverless REST API for managing IoT devices — Python, AWS Lambda, DynamoDB, deployed with AWS SAM.

This service keeps an authoritative list of connected equipment — sensors, gateways, controllers — and lets other software add, look up, search, update and remove them. It is the address book behind the hardware.

About this page, and what it is not This site is generated from the repository on every push: the API documentation is rendered from the real OpenAPI contract, and the coverage report is produced by actually running the test suite in CI. The API itself is not deployed to a public address — a permanently running cloud environment costs money, and no authentication layer has been built yet, so exposing it publicly would be the wrong call. Everything shown here is generated from code and tests, never hand-written.

The API, running

The service runs locally with no AWS account required, backed by an in-memory DynamoDB simulator. This is a real session against the real handler code:

Reproduce it in two commands:

pip install -r requirements-dev.txt
python scripts/local_server.py --seed

Built with

LayerTechnology
ComputeAWS Lambda (Python 3.12), five functions — one per endpoint
RoutingAPI Gateway HTTP API
StorageDynamoDB, with a secondary index for filtering by device type
InfrastructureAWS SAM — every resource declared in template.yaml
CIGitHub Actions: tests, coverage gate, lint, secret scanning
Deployment authGitHub OIDC — no long-lived AWS keys stored anywhere
